# Каталог и показ диалогов

## Подготовка

В **Инструменты → Диалоги** верхний уровень дерева содержит диалоги, нижний — их блоки. Строка диалога открывает общие настройки: название, описание, режим отображения, видимость, первый блок и обзор переходов через ответы. Строка блока открывает его имя, текст, арт, выравнивание, премиальный звук и ответы. Название блока служит подготовке, произнесённый текст хранится отдельно.

Диалог и его блоки редактируют один черновик. Переход между ними сохраняет ввод без подтверждения отмены. **Сохранить** записывает весь диалог с проверкой исходной ревизии; переключение на другой диалог использует обычную проверку несохранённых изменений. JSON импортирует и экспортирует весь диалог, включая настройки показа. Добавление/удаление блока меняет черновик; диалогу нужен хотя бы один блок. Удаление начального блока выбирает оставшийся первый, ссылки ответов на удалённый блок очищаются.

Предпросмотр верхней строки начинается с первого блока, выбранного блока — с него. Он использует текущий черновик и существующую эмуляцию условий, не сохраняет подготовку, не расходует ресурсы и не отправляет игровые сигналы. В Режиссёре каталог доступен для чтения и предпросмотра.

## Показ и аудитория

По умолчанию диалог идёт в чате Foundry и виден только ведущему игроку и мастеру. Мастер может выбрать отдельное окно. В обоих режимах история сохраняет снимки реплик объекта и принятых ответов персонажа; изменение каталога не переписывает старые сообщения. Чат использует Информатора Generics от имени персонажей или токенов. Техническое название диалога не выводится в теле разговора; мастер видит его в заголовке окна.

Сообщение чата начинается с «Диалог между» и имён объекта и персонажа. Текст занимает всю доступную ширину, следом идёт изображение на ширину блока; варианты ответа расположены после изображения. Выравнивание арта слева/справа действует только в отдельном окне и его предпросмотре.

Общая мастерская точка принятого старта (игроком или скриптом) отправляет единственное приватное уведомление мастерам через Информатора. Оно не зависит от режима показа и разрешения публикации оконной истории. Кнопка «Подключиться» открывает отдельное окно наблюдения с полной перепиской, в том числе приватной, без ответов от имени игрока. «Завершить диалог» доступна в уведомлении и окне мастера: обычное завершение освобождает паузу и ожидание скрипта, сигнал завершения не повторяется. Закрытие окна наблюдения не завершает разговор; просмотр не продлевает его время жизни и не регистрирует игрового слушателя. Роль мастера проверяется при чтении и отправке команды, прежний результат после отзыва роли не раскрывает историю.

Видимость действует и для окон, не публикуемых в чат:

- **Приватный**: ведущий игрок и мастер. Другие игроки не подключаются слушателями.
- **Публичный**: допущенные игроки видят реплики объекта и принятые ответы персонажа; варианты и команды ведущего им не передаются.
- **По настройке игрока**: штатный режим бросков Foundry (`core.rollMode`). Публичные броски делают разговор публичным; `gmroll`, `blindroll` и `selfroll` оставляют его приватным.

Публичная аудитория проверяет теги персонажей и расстояние до источника диалога. Белый список требует любого совпадения, чёрный исключает при любом совпадении. Пустые списки не ограничивают теги. Дальность задаётся в единицах сцены; пустое поле (`null`) снимает ограничение, ноль допустим. Эти фильтры показываются также для режима настройки игрока, который может разрешить публичный разговор.

Приватность фиксируется для каждой принятой реплики и ответа. Позднее переключение скрытых бросков на публичные не раскрывает прежний приватный текст, изображения или звук. Слушатель получает только публичную часть истории, в том числе при повторном подключении после приватного отрезка. История без явной отметки публичности не выдаётся слушателям; ведущий сохраняет свой полный разговор. Формат старых записей автоматически не меняется.

Для отдельного окна предусмотрены **Не выводить** (по умолчанию), **По репликам**, **По завершении без запроса** и **По завершении с запросом**. В последнем случае подтверждает ведущий игрок. Получатели определяются той же видимостью и публичными фильтрами. Скрытые режимом поля сохраняют подготовленные значения.

Короткие варианты представлены кнопками, если каждый непустой вариант содержит 1–3 слова и не более 80 символов. Иначе используется радиосписок с кнопками ответа и завершения. Команды ответа доступны только ведущему. Публичная история содержит лишь уже выбранные ответы. Завершение освобождает взаимодействие и ожидание скрипта; оконная история остаётся открытой до закрытия.

## Договор данных и проверки

`normalizeDialoguePresentation` принадлежит чистой модели каталога и возвращает:

```json
{
  "mode": "chat",
  "windowChat": "none",
  "visibility": "private",
  "publicAudience": { "allowTags": [], "denyTags": [], "range": null }
}
```

Допустимые значения: `mode = chat | window`, `windowChat = none | replies | complete | confirm`, `visibility = private | public | player`. Списки тегов состоят из непустых строк; дальность — конечное неотрицательное число или null. Неизвестные значения и неверные типы отклоняются перед записью/импортом. Отсутствующие поля получают значения по умолчанию в памяти. Миграции и записи миров при чтении не выполняются.

`selection` хранит ID диалога и необязательный `pageId`. Выбор страницы не создаёт вторую сущность сохранения и не меняет исходную ревизию. Исчезнувший блок сбрасывает выбор к общим настройкам; несохранённый конфликтующий черновик остаётся защищён проверкой ревизии. Обработчики старых вкладок блоков удалены. Основное дерево использует общий компонент строк Ширмы.

Модель и редактор покрыты `dialogue-asset-editor.test.js` и `dialogue-ide-lifecycle.test.js`. `dialogue-asset-browser-check.mjs` проверяет настоящий DOM и стили Foundry 13/14 на русском и английском: переключение режима, отдельные формы, сохранение общего черновика, предпросмотр выбранного блока, сворачивание дерева и ссылки справки. Проверки используют синтетическую сцену и не обращаются к миру мастера.
