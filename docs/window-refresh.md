# Обновление открытых окон

Изменение источника ссылочных данных должно обновлять открытые окна, которые его используют. Перерисовка не должна обращаться к временно обнулённому черновику. Удаление связанного элемента — ожидаемое изменение данных: выбор сбрасывается либо остаётся явно недоступным.

При фоновом обновлении сохраняются несохранённые значения формы, включая незавершённый JSON. Новые названия и списки ссылок читаются независимо от редактируемого черновика. Его исходная ревизия сохраняется: обновление интерфейса не разрешает перезапись изменений другого окна.

Повторные запросы обновления объединяются. Если новое изменение поступило во время отрисовки, после неё выполняется актуальное обновление. Ввод в ещё видимую старую форму сохраняется вместе с её исходной ревизией. Обработчик устаревшей кнопки повторно проверяет выбранную запись. После ожидания подтверждения действия используются проверенные идентификаторы, а не случайно сменившийся выбор.

Ошибки исполнения, проверки и записи остаются диагностируемыми. Защитная перерисовка не заменяет проверку конфликтов и не скрывает реальные ошибки. Сбой одного окна не останавливает обновление остальных.

Проверки используют синтетическую сцену: совпавшие обновления, ввод во время отрисовки, изменение названия привязанного диалога при незавершённом JSON, исчезновение выбранной записи и отказ сохранения устаревшего черновика. Браузерный сценарий выполняется на Foundry 13/14 в RU/EN, без изменения пользовательского мира.
