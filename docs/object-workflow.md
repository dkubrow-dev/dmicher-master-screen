# Объекты, магазины и диалоги

Проверочный маршрут для версии 0.0.1. Карта, токены, тайлы и предметы создаются мастером обычными средствами Foundry; Ширма не наполняет рабочую сцену демонстрационными объектами.

1. Откройте Конструктор. Красная рамка отмечает область карты в режиме подготовки. Создайте схему; задайте один символ и «Эпизод входа». Новая схема содержит один эпизод, новая сцена не содержит схем.
2. Кликните НИП, выберите «Информация». Назначьте схему, сохраните теги и заметки. В параметрах схемы появится строка этого объекта. Для тайлов и других объектов выберите соответствующий слой Foundry.
3. В «Инструменты → Магазины» создайте два магазина. Выберите строку, задайте имя и изображение, перетащите предметы в ассортимент, укажите запас и необходимость подтверждения мастера. Сохраните каждый магазин.
4. Кликните НИП → «Поведение → Особенности». Выберите магазин и задайте условия: эпизоды, дальность, разрешающие/запрещающие теги, кратность. Повторите для другого НИП. Один и тот же магазин можно назначить нескольким НИП и тайлам; ассортимент и торговая блокировка общие.
5. В «Инструменты → Диалоги» создайте диалог, блоки текста и ответы. Кнопка рядом с изображением открывает штатный FilePicker Foundry. Выберите начальный блок. Ответ либо продолжает разговор, либо завершает его с выбранным событием. Назначьте диалог объекту через его «Особенности».
6. В каталоге откройте предпросмотр инструмента. Выберите схему, эпизод, объект и персонажа, имитируйте теги, расстояние, видимость, активность и расход допуска. Просмотрите обмен и ответы. Предпросмотр хранит изменения только в своём окне; предметы, остатки, события и счётчики мира не меняются. Режим показа при отказе помогает прочитать содержимое ещё не привязанного инструмента.
7. В Режиссёре явно запустите схему. Входной эпизод выбран по умолчанию; просмотр/активация карты и переподключение сами ничего не запускают. Красная рамка исчезнет.
8. Войдите игроком, выберите свой токен и подойдите к объекту. Клик откроет компактное меню с доступными «Диалог» и «Торг». При несоблюдении условий соответствующего пункта нет. Продолжение взаимодействия повторно проверяет актуальные условия.
9. В торговле перенесите предложения в две половины сделки, затем подтвердите или запросите подтверждение мастера. До подтверждения инвентарь не меняется. Мастер видит общую сессию в «Магазинах» и может подключиться. Одна сессия принадлежит одному игроку и одному персонажу; обращение через другого продавца не создаёт второй независимый остаток.
10. Остановите схему или всю сцену. Автоматические действия прекращаются. Диалоги остаются доступны для просмотра, зачитывания и ручного показа мастером без запуска событий.

## Размещение и владение

«Поведение → Переходы → При входе» применяется для объекта один раз при явном запуске. «Смена эпизодов» задаёт положение и видимость при каждом явном входе в выбранный эпизод. Пустые координаты и «Как есть» не меняют состояние. Переподключение ничего не повторяет; расход товаров не восстанавливается при переходе.

Один объект принадлежит только одной схеме. Перед переназначением остановите затронутые схемы. Переназначение очищает прежние привязки инструментов и правила поведения, сохраняя теги и заметки. Сами магазины и диалоги остаются в каталогах. Удаление схемы не удаляет нативный объект карты.

Движение, реплики, эмоции и ожидания задаются в «Поведение → Рутина» по эпизодам. В «Автоматизации» объекта располагаются подписки на события с макросом или типизированным триггером. Отдельная форма прежнего поведения токена удалена; преобразование её данных не выполняется.

В распорядке шаги имеют постоянные номера. Перетаскивание меняет только порядок строк, не номера и связи; выполнение начинается с ID 1. Открытый диалог или магазин приостанавливает распорядок до завершения последнего взаимодействия. Галка «Персонаж игрока» отключает автоматизацию токена, сохраняя возможность взаимодействовать своим персонажем без схемы.

## Границы первой реализации

- Обмен передаёт целые документы Item. Без адаптера системы не рассчитываются количество внутри Item, цены и валюта; денежный блок скрыт.
- Каталог задаёт начальный запас новой позиции. После запуска изменение количества или удаление позиции из подготовки не меняет фактические остатки магазина. Пополнение и списание текущего склада пока не предусмотрены.
- Торговля и разговор поддерживаются на Token и Tile; другие нативные объекты можно назначать схемам и описывать.
- Предпросмотр проверяет выбранные имитируемые условия, а окончательная проверка прав и реальной геометрии выполняется при игре.
- Внешние изображения не включаются в JSON. При переносе подготовки обеспечьте доступность используемых файлов.

## English quick check

Create your scene and NPCs in Foundry. In Constructor, create a scheme and set its entry episode. Click each object → Information to assign its sole owner. Create shops and dialogues under Tools; add stock, blocks, pictures through Foundry's file picker and replies. Attach tools through object Behavior → Features and configure admission per object. Preview can emulate scheme, episode, actor, tags, range and visibility without changing world data or emitting events. Explicitly start the scheme in Director; viewing the scene never starts it. A player selects their own token, approaches and clicks an object to see permitted Trade and Dialogue actions. All access points to one shop share stock and one participant session. After stopping automation, GMs can still read or manually present dialogues.
