# Рабочая ширма

Категория Ширмы в меню Foundry раскрывает подменю, не открывая первый инструмент. **Справка** открывается отдельно. **Ширма** включает панель в сохранённом виде и подсвечивается; повторное нажатие закрывает её. Закрытие из панели также снимает подсветку. Другие категории и инструменты Foundry не закрывают Ширму: мастер может менять активный слой и работать со стенами, светом, звуками и другими объектами.

**Сменить состояние** открывает дерево всех групп сцены с выбором состояния каждой группы. По умолчанию выбрано текущее состояние либо состояние входа. **Отмена** ничего не записывает. **Сохранить** меняет только изменённые группы и сохраняет их статус запуска: остановленная группа остаётся остановленной. Диалог доступен при любом режиме Ширмы. **Старт** явно запускает или перезапускает автоматизацию; **Стоп** останавливает её для всей сцены. В Режиссёре доступны отдельные остановка и запуск группы.

Верхняя строка панели переключает **Конструктор / Режиссёр**, открывает **Актёра**, переносит Ширму в отдельное окно браузера и обратно, меняет положение **справа / снизу** и закрывает её. Закрытие интерфейса не заменяет команду остановки автоматизации.

## Размеры и навигация

Внешняя выделенная граница меняет размер панели и оставшегося стола. Внутренняя граница делит основную и дополнительную зоны. Справа основная зона находится сверху, снизу — слева. Положение, размеры обеих ориентаций, пропорции и состав вкладок сохраняются после перезагрузки. Карта остаётся вне панели. Красная рамка обозначает Конструктор; переход в Режиссёр или закрытие Ширмы её снимает.

Первый уровень меню постоянно виден одной строкой. При переполнении появляются стрелки прокрутки. Категории раскрывают второй уровень поверх содержимого; выбор, уход курсора или Escape закрывают его. Открытие меню не пересоздаёт форму и не теряет ввод. Шестерёнка каждой зоны позволяет скрыть ненужные разделы. В каждой зоне сохраняется хотя бы одна доступная вкладка.

Меню основной зоны: **Сцена**, **Инструменты → Магазины / Диалоги**, **Автоматизация → Сигналы / Макросы**, **Иное**. Каждый конечный раздел хранит свой выбор и черновик отдельно для сцены и режима. При выборе другого элемента той же вкладки запрашивается решение о несохранённых изменениях. Вложенные кнопки строки выполняют своё действие; свободная часть строки выбирает элемент.

## Сцена и инструменты

В дереве сцены **группа** объединяет объекты с общей схемой поведения, **состояние** определяет их текущий режим. Новая сцена не содержит групп. Явное создание группы сразу добавляет одно состояние. Последнее состояние группы удалить нельзя, последнюю группу сцены удалить можно после остановки.

Группа имеет имя, описание, символ из одной видимой графемы, цвета, обязательное состояние входа и таблицу объектов. Один объект принадлежит одной группе. Значки групп показывают выбранное состояние и статус запуска, не исполняя подготовку. Открытие карты не запускает автоматизацию. Состояние с названием «Остановка» само по себе ничем не отличается от остальных: остановка выполняется отдельной командой.

Каталоги магазинов и диалогов независимы от точек доступа. В **Поведение → Особенности** объект получает нужные инструменты по состояниям. Один объект может открывать несколько магазинов и диалогов. Обратные ссылки в каталоге показывают объекты, группы, состояния и допуск. **Предпросмотр** имитирует условия, не меняет мир и не отправляет сигналы.

## Сигналы и макросы

Раздел **Сигналы** показывает дерево: группа → эмитент → объявленные сигналы. В конце находятся эмитенты без группы. Кнопка «+» у эмитента добавляет его сигнал. Выбор сигнала открывает название, описание, типизированные параметры, возврат и подписчиков. Системные сигналы и поля защищены; добавленные пользовательские поля редактируются отдельно. Пользовательские названия не ограничены латиницей.

Раздел **Макросы** позволяет выбрать объект-владельца, прикрепить документ из Foundry и открыть штатный редактор. Список показывает результат проверки. Подписка связывает макрос объекта с сигналом конкретного эмитента. При несоответствии интерфейса форма показывает ошибку и заготовку для кода; сохранить несовместимую подписку нельзя. Подписки не требуют использования всех входящих полей, но должны предоставлять весь объявленный возврат.

**Иное** содержит подготовку зон и прямых действий, разовую паузу, звук, подкрепления, рабочие окна, перенос сцены и оперативные инструменты Режиссёра. Зоны испускают объявленный сигнал группы, прямые взаимодействия — сигнал объекта. Сохранение этих блоков не запускает подготовленные действия.

Встроенная справка доступна на русском и английском. Значки вопроса дают краткую подсказку и открывают нужную страницу; они исключены из последовательности Tab.
