# Быстродействие представлений и движения

Стоимость работы на компьютере игрока важнее точного повторного вычисления всех данных на каждом кадре. Нативная анимация Foundry отвечает за плавность; движок Ширмы задаёт ограниченные по частоте участки и сохраняет возможность немедленной остановки.

## Исправленные источники нагрузки

- `refreshToken` и аналогичные кадровые хуки объектов обновляют только подготовленные украшения. Они не читают флаги сцены, не нормализуют определения групп и не перебирают историю скриптов. Объект без украшений сразу выходит из обработки. Изменение Scene обновляет содержание украшений; один снимок групп используется для всех объектов.
- Значки групп в навигации сохраняют существующий DOM, пока видимое состояние не изменилось. Изменение часов скрипта не удаляет и не вставляет те же значки заново.
- Консоль читает только новые записи и добавляет строки пакетом. Подробный JSON формируется при раскрытии. Объём истории ограничен; обычное добавление в конец не измеряет геометрию всех накопленных строк.

Обработка игрового состояния остаётся в Ширме. Эти изменения не требуют новых библиотек, ресурсов при старте, изменения Generics или Premium и не меняют подготовку миров.

## Последний участок движения

Foundry временно меняет подготовленные `document.x/y` во время показа промежуточного кадра; подтверждённые координаты находятся в нативном `_source`. Пересчёт следующего участка от промежуточного кадра накапливал отставание при уже уменьшенном остатке времени. В конце исполнитель пытался пройти остаток пути быстрее. Расчёт движения теперь использует подтверждённую геометрию, сохраняя нативные ручные изменения; длительность анимации соответствует времени участка.

## Проверки

Регрессии проверяют отсутствие чтений Scene на кадровых хуках всех поддерживаемых типов, отсутствие геометрической работы для объектов без украшений, сохранение DOM навигации, равномерность отрезков при промежуточных кадрах, отмену и ручное перемещение. Браузерные проверки консоли используют синтетический заполненный журнал и нативные стили Foundry 13/14. Они измеряют стоимость интерфейса, а не обещают определённый FPS пользовательского мира.

Повторяемое измерение: `node scripts/director-console-performance-check.mjs`. На 500 строках при 100 последовательных добавлениях получены следующие результаты (14 сентября 2026):

| Foundry | Медиана до / после, мс | p95 до / после, мс |
| --- | --- | --- |
| 13.351 | 10,0 / 3,0 | 13,1 / 4,4 |
| 14.366 | 11,8 / 3,3 | 17,6 / 5,5 |

За эти 100 добавлений клонируется 100 новых записей вместо 50 000. При следовании за концом журнала не выполняется поиск прямоугольников строк (ранее около 98 000 вызовов). Layout браузера остаётся необходимым при добавлении текста; это не утверждение об отсутствии всей работы браузера. Исходные отчёты находятся в `../artifacts/dmicher-master-screen/0.0.1/console-review/performance-{baseline,current}.json`.
