# Скрипты объектов

`script-model.js` задаёт один формат для `initialScript`, `transitionScripts[stateId]` и `scripts[]` рутины. Скрипт содержит имя, enabled, repeat, combat и steps. В рутине обязателен stateId; один скрипт каждого назначения на состояние. Массив шагов — визуальный порядок, граф использует постоянные положительные ID. Старт и повтор — ID 1. Удалённые цели отбрасываются, пустые next завершают скрипт, несколько целей выбираются случайно.

| Действие | Основные параметры |
| --- | --- |
| wait | seconds > 0 |
| move | timeMode duration/speed; duration; position{x,y,speed}; rotation{mode,angle,speed}; size{x,y,z,speed} |
| visibility | visible |
| speech | duration; chat{enabled,timing,text,allowTags,denyTags,range,deleteAfter}; bubble{enabled,text,fontSize} |
| emotion | emoji, duration |
| sound | src, volume |
| signal | signalId, parameters, before, after |
| macro | macroUuid, before, after |

Неиспользуемые части движения равны null. X/Y размера — клетки сетки; Tile и Drawing переводят их в пиксели. Drawing изменяет shape и при необходимости точки полигона. Wall перемещается относительно середины сегмента и поворачивается через координаты c. MeasuredTemplate использует direction. Region переносит геометрические shapes; неподвижные нативные типы фигур не маскируются произвольными x/y. Z — нативная глубина Token в Foundry 14, не elevation и не эмуляция в 13. В режиме duration ноль означает мгновенное изменение. Относительный поворот сохраняет весь указанный угол, включая несколько оборотов.

`apps/script-parameters.js` формирует единые таблицы для всех назначений скрипта. Новое действие получает полный шаблон; движение — текущую геометрию документа. Режим определяет видимые поля, JSON сохраняет значения остальных режимов. Явный null отключает поддействие. Обновление таблицы и JSON меняет один черновик; невалидный ввод блокирует сохранение. Это редактор текущего формата, не миграция сцены.

У реплики duration=0 сохраняет пузырь до следующей реплики; у эмоции — до следующей эмоции. Чат «до» удаляется по окончании заданной длительности, если deleteAfter; чат «после» появляется после неё и живёт ещё заданную длительность, чтобы его можно было прочитать. Только разрешённые теги HTML форматирования и изображения остаются в чате. Пузырь — простой текст. Дальность 0 не ограничивает аудиторию; владение, теги и видимость проверяются, пользователь не получает дубликаты за несколько персонажей.

`ObjectScriptRuntime` хранит прогресс по объекту, назначению скрипта и ID/stateId. Остаток времени очищается явно при смене шага: рекурсивное слияние Foundry не может вернуть таймер предыдущего ожидания. Выполнение внешнего действия отделено от сцепленной записи состояния; неизвестный результат не переигрывается после восстановления. Торговля и активный диалог замораживают часы объекта, возобновление не наверстывает паузу.

Вход в состояние сначала исполняет скрипт перехода, затем его рутину. Исходный скрипт запускается явной командой, работает через тот же исполнитель и временно приостанавливает обычный скрипт объекта. Его ручной запуск не является стартом группы. Аварийный стоп отменяет дальнейшие шаги; произвольный уже исполняемый JavaScript насильно не прерывается.

## Бой

Нативный адаптер определяет бой, текущий ход и объект. Использование в бою выключено по умолчанию. `turnSeconds` задаёт бюджет длительных действий; по умолчанию 6 секунд. Подтверждение позволяет продолжить, пропустить текущий ход либо остановить скрипт данного объекта до конца боя. Уведомление может быть предупреждением и/или приватным сообщением Информатора мастерам. `endTurn` завершает только ожидаемый актуальный ход.

Прогресс длительного движения сохраняет конечную цель и оставшееся время. Ручное изменение между ходами становится новым началом движения к той же цели. Модуль не угадывает системные ресурсы действий, инициативу или доступную по правилам скорость.
